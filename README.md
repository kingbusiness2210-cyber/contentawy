# Contentawy (كونتنتاوي) 🚀

> **مساعدك التسويقي الأول لإدارة الحملات والمحتوى والأفكار والحاسبات الذكية.**

---

## 🌟 مميزات التطبيق:
- **إدارة الحملات الإعلانية ومتابعة الـ ROAS:** تتبع الإنفاق والعائد وصافي الأرباح لكل حملة (Meta, TikTok, Google, Snapchat, LinkedIn).
- **جدول وخطة المحتوى الذكي:** إدارة أفكار الريلز، الكاروسيل، السكريبتات، مع نسخ سريع للكابشن والهاشتاجات.
- **أدوات وحاسبات التسويق:**
  - حاسبة الـ ROAS والـ ROI وصافي الربح.
  - حاسبة تكلفة اكتساب العميل (CAC) والقيمة الدائمة (LTV).
  - حاسبة نقطة التعادل (Break-Even ROAS).
  - منشئ روابط التتبع (UTM Campaign URL Builder).
  - بنك الصيغ الإعلانية وأقوى خطافات لفت الانتباه (Viral Hooks & Formulas).
- **بنك الأفكار والإلهام:** تدوين سريع للأفكار مع إمكانية تحويل أي فكرة مباشرة إلى منشور في الجدول أو حملة إعلانية.
- **قائمة المهام اليومية:** مع تنبيهات المهام العاجلة وتفاعل لمسي (Haptic Feedback).
- **Offline First:** حفظ كافة البيانات محلياً على الجهاز مع ميزة النسخ الاحتياطي والاستعادة (Backup & Restore).
- **تصميم بريميوم:** مظهر عصري يدعم الوضعين المظلم والفاتح (Dark & Light Mode).
